## 🚀 GUIDE PAS-À-PAS : METTRE LE PORTFOLIO EN LIGNE SUR VERCEL

Vercel est gratuit et mettra votre site en ligne en moins de 30 secondes avec un nom de domaine personnalisé sécurisé.

### Étape 1 : Publier votre projet sur GitHub
1. Connectez-vous sur [GitHub](https://github.com/mouandzahandy16).
2. Créez un nouveau dépôt public nommé **`portfolio`** (via [github.com/new](https://github.com/new)).
3. Glissez/Importez tous les fichiers de ce dossier (`index.html`, `style.css`, `script.js`, `CV_Handy_Christopher.html`, etc.) directement sur la page de votre dépôt.

### Étape 2 : Connecter Vercel à GitHub
1. Allez sur **[vercel.com](https://vercel.com)** et créez votre compte en cliquant sur **"Continue with GitHub"**.
2. Une fois connecté sur votre tableau de bord Vercel, cliquez sur le bouton **"Add New..."** ➔ **"Project"**.
3. Dans la liste de vos projets GitHub, sélectionnez votre dépôt **`portfolio`** et cliquez sur **"Import"**.

### Étape 3 : Déployer
1. Laissez les options par défaut (`Framework Preset: Other` et `Root Directory: ./`).
2. Cliquez sur **"Deploy"**.
3. En moins de 20 secondes, votre site est **EN LIGNE** avec une URL comme `https://portfolio-mouandzahandy16.vercel.app` accessible dans le monde entier !
