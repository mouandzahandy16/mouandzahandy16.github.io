# Handy Christopher Portfolio

Personal portfolio for MOUANDZA Handy Christopher.

## Files
- `index.html` — main portfolio page
- `style.css` — responsive dark/violet design
- `script.js` — mobile menu and current year
- `CV_Handy_Christopher.pdf` — CV
- `Project_Description.txt` — project proposal

## Before publishing
Replace:
- `YOUR_EMAIL@example.com`
- `+250 XXX XXX XXX`
- `YOUR_GITHUB`
- `YOUR_LINKEDIN`

Then upload the folder to GitHub and enable GitHub Pages, or import the repository into Vercel/Netlify.

## GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and the CV PDF.
3. Go to Settings → Pages.
4. Select the main branch and root folder.
5. Save and open the generated website URL.
