## 🌐 Comment mettre le portfolio EN LIGNE (Pas en local)

Voici les 3 méthodes gratuites et simples pour publier votre site en ligne afin que n'importe qui puisse y accéder avec une adresse web (URL) :

### Méthode 1 : GitHub Pages (Recommandée)
Puisque vous avez déjà un compte GitHub ([mouandzahandy16](https://github.com/mouandzahandy16)) :

1. Allez sur [github.com/new](https://github.com/new).
2. Nommez votre dépôt `portfolio` (ou `mouandzahandy16.github.io`).
3. Laissez le dépôt en **Public** et cliquez sur **Create repository**.
4. Importez tous les fichiers de ce dossier (`index.html`, `style.css`, `script.js`, `CV_Handy_Christopher.html`, etc.) dans ce dépôt GitHub.
5. Allez dans les réglages du dépôt : **Settings** (Roue dentée) ➔ **Pages** (dans le menu de gauche).
6. Sous **Build and deployment / Source**, sélectionnez la branche `main` (ou `master`) et le dossier `/ (root)`.
7. Cliquez sur **Save**.
8. En 1 à 2 minutes, GitHub génèrera votre adresse en ligne : `https://mouandzahandy16.github.io/portfolio` !

---

### Méthode 2 : Netlify Drop (Le plus rapide - Sans commande)
1. Rendez-vous sur le site [app.netlify.com/drop](https://app.netlify.com/drop).
2. Faites un simple **glisser-déposer (Drag & Drop)** du dossier contenant vos fichiers directement sur la page web.
3. Netlify publiera votre site instantanément en 10 secondes et vous fournira un lien en `.netlify.app` accessible partout dans le monde !

---

### Méthode 3 : Vercel
1. Connectez-vous sur [vercel.com](https://vercel.com) en utilisant votre compte GitHub `mouandzahandy16`.
2. Cliquez sur **Add New...** ➔ **Project**.
3. Sélectionnez votre dépôt GitHub `portfolio`.
4. Cliquez sur **Deploy**. Votre site sera instantanément en ligne avec HTTPS gratuit.
